# ❤️ Heart Disease Prediction

A machine learning-based web application that predicts the risk of heart disease based on clinical and health-related parameters. The project uses a **K-Nearest Neighbors (KNN)** classifier and provides an interactive interface built with **Streamlit**.

## 🚀 Live Demo

**Streamlit App:**
https://heart-disease-prediction-knn-sw.streamlit.app/

## 📌 Project Overview

Heart disease is one of the major health challenges worldwide, and early identification of potential risk can support further medical evaluation.

This project uses a supervised machine learning approach to analyze patient-related features and predict whether the given inputs indicate a **higher or lower risk of heart disease**.

The trained KNN model is integrated into a Streamlit application, allowing users to enter patient information and receive a real-time prediction.

> **Disclaimer:** This application is intended for educational and demonstration purposes only. It is not a medical diagnostic tool and should not be used as a substitute for professional medical advice.

## 📋 Input Features

The application takes the following patient information:

* **Age**
* **Sex**
* **Chest Pain Type**
* **Resting Blood Pressure**
* **Cholesterol**
* **Fasting Blood Sugar**
* **Resting ECG**
* **Maximum Heart Rate**
* **Exercise-Induced Angina**
* **Oldpeak (ST Depression)**
* **ST Slope**

These inputs are processed and transformed into the feature format expected by the trained model.

## ⚙️ How It Works

```text
User Input
    ↓
Streamlit Interface
    ↓
Data Preprocessing
    ↓
Categorical Feature Encoding
    ↓
Feature Scaling
    ↓
KNN Model
    ↓
Prediction
    ↓
Risk Result
```

The application loads three serialized objects:

* `KNN_heart.pkl` — trained KNN model
* `scaler.pkl` — StandardScaler used for numerical features
* `columns.pkl` — expected feature columns and their order

The input data is aligned with the model's expected features before prediction.

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/swastik-da/Heart-Disease-Prediction.git
cd Heart-Disease-Prediction
```

### 2. Create a virtual environment

Using Conda:

```bash
conda create -n heartapp python=3.11
conda activate heartapp
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.

## 🔮 Prediction Output

After entering the required information and clicking **Predict**, the application displays one of two results:

* ⚠️ **High Risk of Heart Disease**
* ✅ **Low Risk of Heart Disease**

The prediction is generated by the trained KNN classification model.
